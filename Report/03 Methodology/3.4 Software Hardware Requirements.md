## 3.4.1 Software and Hardware Requirements Summary

The proposed DMS prototype requires an embedded computing unit, AI acceleration support, an in-cabin IR-capable camera, a wearable vital-sign sensor, and a lightweight software stack for real-time inference, logging, and alert generation.

### Table 3-12: Software and Hardware Requirements Summary

| Requirement Area | Recommended Item / Tool | Purpose in the System |
| --- | --- | --- |
| Edge compute | Raspberry Pi 5 (8GB) | Runs the camera pipeline, sensor interface, local logging, and real-time control logic. |
| AI acceleration | Raspberry Pi AI HAT+ 26 TOPS | Accelerates computer-vision inference such as eye state, head pose, gaze, and phone-use detection. |
| Camera | Pi IR camera 5MP 160° or NoIR Camera Module 3 upgrade path | Captures the driver face and upper-body region under normal and low-light cabin conditions. |
| Wearable sensor | MAX30102 wristband module | Measures heart rate and supports HRV-related fatigue/stress analysis. |
| Core software | Python, OpenCV, MediaPipe Face Mesh, YOLO-based detector, sensor interface libraries | Provides facial landmarks, PERCLOS calculation, gaze/head-pose estimation, phone detection, and sensor acquisition. |
| Dataset/annotation tools | CVAT, Roboflow, Labeling tools | Supports annotation of eye closure, gaze direction, head pose, and phone-usage classes. |
| Alerting/logging | Buzzer/vibration motor, timestamped event log, optional dashboard | Converts detections into real-time warnings and stores risky events for review. |
